# AURA

AURA es un e-commerce full stack especializado en perfumes de diseñador y perfumes árabes.

El proyecto fue desarrollado como parte de mi portafolio de desarrollo de software y combina una experiencia de compra moderna con gestión de inventario, pagos, pedidos y recomendaciones inteligentes.

## Tecnologías

### Frontend

- React
- TypeScript
- Vite
- React Router
- Lucide React
- Mercado Pago SDK

### Backend

- Python
- FastAPI
- SQLAlchemy
- PostgreSQL
- Alembic
- JWT
- Argon2
- Resend
- Jinja2

## Funcionalidades actuales

- Registro e inicio de sesión
- Verificación de correo electrónico
- Recuperación de contraseña
- Catálogo de perfumes
- Detalle de productos
- Carrito de compras
- Direcciones de entrega
- Checkout
- Integración con Mercado Pago
- Reserva y control de stock
- Historial de pedidos
- Panel administrativo
- Gestión de productos
- Gestión de clientes
- Gestión de inventario
- Gestión de pedidos
- Horarios de procesamiento
- Correos de confirmación, despacho y entrega
